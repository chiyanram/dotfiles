# Scope shellcheck/shfmt enforcement to the `dot` command surface, not all of `bin/`

`bin/` contains both the `dot` command surface (`bin/dot`, `bin/dot-*`, `bin/lib/*.sh`) and ~20 unrelated personal utility scripts (`isdir`, `jwt`, `colortest`, `git-clc`, etc.) that predate `dot` and follow none of its conventions (no `# Description:` header, no `common.sh` sourcing). `.pre-commit-config.yaml`'s shellcheck hook had accidentally widened to catch both (`bin/[^/]+` matches any top-level `bin/` file), diverging from `dot-test`'s own `bash_scripts()` list and running shellcheck twice on the overlap. Decided: `dot-test`'s `bash_scripts()` is the single canonical list of what this repo holds to engineering rigor; the personal utility scripts are deliberately out of scope. Pre-commit's own shellcheck hook was removed entirely rather than realigned, since after this decision the two lists would be identical and running shellcheck twice is wasted work.
